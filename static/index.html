How To Use

Upload images, select a tool, then draw directly on the canvas. Use Detect to add AI boxes to the current image.

Mouse wheel zooms. Middle-drag, Shift-drag, or Move mode pans. Right-click erases an annotation under the pointer.

Shortcuts: M move, 1 rectangle, 2 circle, 3 text, 4 crop, 5 erase, D detect, Ctrl+O upload, Ctrl+S export, Ctrl+Z undo, Delete clear, arrow keys navigate.
